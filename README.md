## Cele's Blog

蓝白配色取自头像（`#4696d2`），结构参考 didilili / krislinzhao / zotero-chinese。

### 🎓 词汇学习

- [3500 · 高考英语词汇](https://celeslime.github.io/3500/) — 5500 的旧版词库，未同步更新
- [5500 · 考研英语词汇](https://celeslime.github.io/5500/) — 考研 5500 词的查询、联想与朗读

### 🎮 游戏相关

- [syw · 原神面板计算器](https://celeslime.github.io/syw/) — 原神面板计算，早期算法探索（拉格朗日方程）
- [simcity · 城市模拟](https://celeslime.github.io/simcity/war/) — 城市模拟经营，单纯形算法探索

### 🧸 玩具盒子

- [universe · 星球模拟](https://celeslime.github.io/universe/) — 万有引力下的星球运动模拟
- [timer · 计时器](https://celeslime.github.io/timer/) — 极简时钟，环形倒计时原型

### 💡 在做的

- 头像生成 — 用 Python 脚本生成的 flower 头像
- 3D char Render — 3D 字符渲染实验，整理旧 demo 中
- 对话树 — wordcloud 升级版，对话任务分类树

### 仓库结构

各应用均为独立仓库，通过 GitHub Actions 自动部署到本仓库对应的子路径；
`index.html` 为聚合主页，纯静态 HTML/CSS/JS，无构建依赖。
