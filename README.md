- [5500 · 考研英语词汇](https://celeslime.github.io/5500/) — 考研 5500 词的查询、联想与朗读

### 🧸 玩具盒子

- [universe · 星球模拟](https://celeslime.github.io/universe/) — 万有引力下的星球运动模拟

### 仓库结构

各应用均为独立仓库，通过 GitHub Actions 自动部署到本仓库对应的子路径；
`index.html` 为聚合主页，纯静态 HTML/CSS/JS，无构建依赖。
